# Desain UI/UX

Aset desain untuk Afindo Learn.

| File | Isi |
|---|---|
| `afindo-learn.figcraft` | File sumber (format FigCraft). Tiga halaman: Design System, Desktop (9 layar 1280px), Mobile (3 layar 375px). Layar memakai instance komponen. |
| `afindo-learn-preview.pdf` | Ringkasan 13 halaman: cover, design system, 9 layar desktop, 3 layar mobile, dan catatan. Cocok untuk dilihat tanpa membuka file desain. |
| `preview/*.png` | Preview per layar (9 desktop, 3 mobile). |

Catatan: di file desain font **Geist** diganti **Inter** karena Geist tidak tersedia di FigCraft; aplikasi tetap memakai Geist.

Halaman aplikasi yang sudah diimplementasikan didokumentasikan dengan screenshot asli di [`docs/DESIGN.md`](../docs/DESIGN.md) §8.
